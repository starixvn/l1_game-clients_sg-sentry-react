🧪 SG Sentry Dev - Error Simulation Demo

🎯 Overview

This demo shows how to use the error simulation functionality to test Sentry session replay in the SG Sentry Dev component.

✅ Status: Error simulation system is ready for testing

🚀 Quick Start

To enable error simulation, set the testMode prop to true:

import App from './src/app'; // Initialize with test mode enabled <App appEnv="test" siteId="test-site-123" language="en" testMode={true} // This enables the error testing page />

🧪 Available Error Types

1. Null Reference Error

Simulates accessing properties of null objects:

const nullObject: any = null; const result = nullObject.someProperty.length; // Throws TypeError

2. Network Error

Simulates failed network requests:

const response = await fetch('https://invalid-url-that-will-fail.com/api/test'); const data = await response.json(); // Throws network error

3. State Error

Simulates state mutation errors (like the original MainPlayerStore issue):

const state = { games: null }; const gameCount = state.games.length; // Throws TypeError

4. MainPlayerStore Error

Simulates the exact original error from MainPlayerStore.handleOfferGames:

const mainPlayerStore = { offerGames: null }; const handleOfferGames = (offerGames) => { return offerGames.length; // Throws: "Cannot read properties of null (reading 'length')" }; handleOfferGames(mainPlayerStore.offerGames);

5. Workflow Error

Simulates workflow step failures:

await workflowTracker.track('Failing Step', async () => { throw new Error('Workflow step intentionally failed for testing'); });

6. Performance Error

Simulates slow operations:

await trackPerformance('Slow Operation', async () => { await new Promise(resolve => setTimeout(resolve, 5000)); throw new Error('Performance threshold exceeded'); });

7. User Interaction Error

Simulates DOM element not found:

const element = document.querySelector('.non-existent-element'); if (!element) { throw new Error('Element not found for user action'); }

📊 Session Replay Breadcrumbs

All error simulations create detailed session replay breadcrumbs:

logError('Session replay: [Error Type] error occurred', { error: errorMessage, errorType: 'specific_error_type', timestamp: Date.now(), operation: 'operation_name', // Additional context specific to each error type });
📋 Breadcrumb Metadata:
  • error: The actual error message
  • errorType: Type of error being simulated
  • timestamp: When the error occurred
  • operation: Operation that triggered the error
  • Additional context: Error-specific metadata

🎮 Using the Error Simulator

Quick Error Tests

Use the quick test buttons to simulate immediate errors:

  • 🚨 Simulate Error: Triggers an immediate error
  • ⚠️ Simulate Warning: Triggers a warning message
  • ℹ️ Simulate Info: Triggers an info message

Comprehensive Error Simulator

Click "Show Error Simulator" to access the full testing interface:

  • Individual Error Buttons: Test specific error types
  • Random Error: Randomly selects an error type
  • Auto Simulation: Automatically triggers errors every 10 seconds
  • Error Count: Track how many errors have been simulated
  • Reset Count: Clear the error counter
